# Personal Expense Tracker

A Python-based Expense Tracker that helps users record daily expenses, categorize spending, and generate monthly financial reports.

## Features

- Add daily expenses
- View all expenses
- Monthly summary
- Category-wise analysis
- Highest spending category detection
- CSV file storage

## Tech Stack

Python, CSV, File Handling, Exception Handling, Datetime Module, GitHub, Visual Studio Code

## Resume Description

Developed a Python-based Personal Expense Tracker to record daily expenses, categorize spending, and generate monthly financial reports using CSV file handling.
