# 💰 Personal Expense Tracker & Monthly Financial Report System

## 📌 Project Overview

Managing daily expenses is important for better financial planning.  
This Python-based Personal Expense Tracker helps users record daily expenses, organize them by category, and generate monthly financial reports easily.

Instead of writing expenses manually, this system stores everything in a CSV file and provides quick monthly summaries for smarter money management 📊

It is simple, practical, and useful for real-life financial tracking.

---

## ✨ Features

✅ Add daily expense records  
✅ Categorize expenses (Food, Travel, Shopping, Bills, etc.)  
✅ Store records using CSV files  
✅ View all saved expenses  
✅ Generate monthly spending summary  
✅ Category-wise spending analysis  
✅ Detect highest spending category  
✅ Automatic CSV file creation

---

## 🛠 Tech Stack

Python, CSV, File Handling, Exception Handling, Datetime Module, GitHub, Visual Studio Code
